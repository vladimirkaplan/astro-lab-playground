# astro lab playground (working title)

Practice simulations for an introductory astronomy lab course: every lab as a
readable explanation plus an interactive imitation you can run in the browser, so you can
understand and rehearse a lab before touching the real equipment.

Unofficial student project. Not affiliated with, or sanctioned by, any college. This is a
learning tool, not a way to skip a lab or submit fake work: do the real lab, follow your
instructor's rules.

Status: planning phase. `GOAL.md` is the build brief (phases 0 to 3, hard rules, done
criteria). The site will live in `site/` once building starts; plain HTML and canvas, no
build step, works offline once loaded.

Licensed MIT (code) and CC BY 4.0 (prose) once the public repo is set up. Public course
material like the textbook chapter texts is referenced, never copied.
