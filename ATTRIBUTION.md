# Image attribution (site/img/)

These ten files are the galaxy photographs used by **Lab 14: galaxy
identification** (`site/labs/14-galaxy-id/`). Every image comes from
**Wikimedia Commons** and is used under the licence recorded per file below
(public domain, CC0, CC BY or CC BY-SA - the lab's licence gate, board-approved
2026-11-08). Each was fetched as the Commons 1280-pixel-wide rendition of the
file named (or the original where the original was already narrower).

In the site's own UI, each image carries its credit line and licence directly
beneath it on the page (rendered by Lab 14's benches), and the shared licence
footer names the site's own licences. The site's own code is MIT
(see LICENSE); the site's own prose is CC BY 4.0 (see LICENSE.docs.md). The
image licences below apply to the image files only.

Per file: object, file name in `site/img/`, the Commons source page, the
direct image URL as downloaded, the exact `LicenseShortName` reported by the
Commons API at fetch time (2026-11-08), and the credit line as displayed.
